Impact of social media on life

A data analysis project that investigates which of three social media habits is most strongly associated with perceived stress among students:
Daily social media usage duration
Late-night social media usage
Frequency of social comparison

Which of three social media habits — daily usage duration, late-night usage, or frequency of social comparison — is most strongly associated with perceived stress among students?

The dataset used in this project is Impact of Social Media on Life from Kaggle.
https://github.com/BibifatemehVahabZadehMousavi/DLT.A2.Mahi.Tate.Bibi/tree/de2b59c9184872b97795c2e5bbf9623d7b3b7370/data
We selected this dataset because it contains information about students' social media habits, stress levels, and related factors. The dataset was cleaned and prepared before analysis. Both the original and cleaned versions can be found in this repository.

Method to structure the Algorithm:
Load and clean the dataset.
Convert categorical values to numerical values.
Check for missing or invalid data.
Calculate average ranks.
Calculate correlations between variables and perceived stress.
Compare the results to identify the strongest association.

The analysis showed that daily social media usage has the strongest association with perceived stress (r ≈ 0.75). Late-night usage showed a weaker association (r ≈ 0.28), while social comparison showed almost no association. These results indicate a relationship between the variables, but not a cause-and-effect relationship.
