Impact of Social Media

The pseudocode

The pseudocode is structured into three main functions: load_records, average_ranks, and correlation_or_none. The load_records function reads the CSV dataset, converts categorical values into numbers, and skips invalid records. The average_ranks function assigns ranks to values and calculates average ranks for tied values. The correlation_or_none function calculates Pearson correlation when sufficient valid data is available. Finally, the main program calculates the three correlations between social media habits and perceived stress, displays the results, and identifies the habit with the strongest observed association by comparing the absolute correlation coefficients.

Pseudocode: Social Media Habits and Perceived Stress 

START
		#SET CSV file path to a variable
		SET filename to the CSV dataset path
        
		#ASIGN to each text for Social_Comparison_Frequency a number
			    
		CREATE Social_Comparison_Frequency:
		    "never" = 1
		    "rarely" = 2
		    "sometimes" = 3
		    "frequently" = 4
		    "always" = 5
			  
		#ASIGN to each text for Late_Night_Usage a number
		CREATE late_night_codes:
		    "true", "yes", "1" = 1
		    "false", "no", "0" = 0
		
		#The load_records function creates all lists for the dataset, 
		#converts the values to numbers, 
		#checks for missing or invalid values, and then adds the values to the lists.
		FUNCTION load_records(filename):
		
		    CREATE empty list records
		    OPEN the CSV file
		    READ the dataset row by row
		
		    FOR each row in the dataset:
		
		        TRY:
		            CONVERT Perceived_Stress_Score to a number and SET it in stress
		            CONVERT Daily_Usage_Hours to a number and SET it in hours
		            CONVERT Late_Night_Usage to its numeric value and SET it in late_night
		            CONVERT Social_Comparison_Frequency to its numeric value and SET it in comparison
			  
	        	#Here we checked again the values of each fields before we add them to lists
		        IF any value is missing, invalid or unrecognized:
		            SKIP the row
		
		        OTHERWISE:
		            ADD stress, hours, late_night,
		            and comparison to lists
		
		    RETURN lists
		
		#This function is used for the list Late_Night_Usage and  
		#Social_Comparison_Frequency when we count for 
		#their relation to Perceived_Stress_Score 
			  
		FUNCTION average_ranks(values):
		    CREATE list ranks with the same length as values
		    SORT the positions of values from smallest to largest value
		    SET start = 0
		    WHILE start < length of values:
		        SET group_size = number of equal values starting at start
		        SET average_rank = (start + 1 + start + group_size) / 2
		        FOR each position in this group:
		            SET ranks[position] = average_rank
		        END FOR
		        SET start = start + group_size
		    END WHILE
		    RETURN ranks
        END FUNCTION

		#The function corelation_or none calculate the Pearson coefficient r
		FUNCTION correlation_or_none(x, y):
		    #Each x value must be paired with a y value from the same student
		    IF x and y have different lengths:
		        RETURN unavailable
		    IF either list has only one distinct value:
		        RETURN unavailable
		    #Use the imported tool to calculate Pearson r (between -1 and 1)
		    CALCULATE Pearson correlation between x and y
		    RETURN correlation coefficient
		END FUNCTION

		#Main program 
		#Loads all records by calling the function load_records
				
		SET records = load_records(filename)
        #Here calculates all correlations 
				
	    #1. calculate correlation between Daily_Usage_Hours and Perceived_Stress_Score
		SET r1=correlation_or_none(Daily_Usage_Hours, Perceived_Stress_Score)
				
		#2. calculate average rank and correlation between Late_Night_Usage and Perceived_Stress_Score			
	    SET A1=average_ranks(Late_Night_Usage)
		SET r2= correlation_or_none(A1, Perceived_Stress_Score) 
				
		#3. calculate average rank and correlation between Social_Comparison_Frequency and Perceived_Stress_Score		
		SET A2=	average_ranks(Social_Comparison_Frequency)
		SET r3=average_ranks(A2,Perceived_Stress_Score)
		
	
		
		DISPLAY number of valid students
	    DISPLAY all three correlation coefficients
		
	    CREATE a list available to sort the coefficients
		
	    FOR each correlation coefficient:
			IF the coefficient is available:
		        ADD its position and value to available
		
		    IF available is empty:
		
		        DISPLAY "Could not calculate the correlations."
		
		    OTHERWISE:
		
		        FIND the coefficient with the largest
		        absolute value
		
		        IDENTIFY the corresponding social media habit
		
		        DISPLAY the strongest observed association
		        DISPLAY its coefficient rounded to 3 decimals
		
		        DISPLAY "Correlation shows association,
		        not causation."
		
		END
