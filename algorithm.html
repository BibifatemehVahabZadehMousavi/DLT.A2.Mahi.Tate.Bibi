Impact of Social Media

The pseudocode

The pseudocode is structured into three main functions: load_records, average_ranks, and correlation_or_none. This structure was chosen to make the algorithm easier to understand, test, and maintain. The load_records function handles data preparation and validation to ensure that only reliable records are analysed. The average_ranks function was included because ranking allows variables measured on different scales to be compared fairly and correctly handles tied values. The correlation_or_none function calculates Pearson correlation only when sufficient valid data exists, which helps avoid unreliable results. Dividing the algorithm into separate functions improves readability and ensures that each function has a clear responsibility. Finally, the main program calculates the three correlations between social media habits and perceived stress, displays the results, and identifies the habit with the strongest observed association by comparing the absolute correlation coefficients.
