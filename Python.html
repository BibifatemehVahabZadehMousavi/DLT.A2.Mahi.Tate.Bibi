Impact of Social Media

The python resource code

The code is written in python and structured into three functions and the main code: load_records, average_ranks, and correlation_or_none. The load_records function reads the CSV dataset, converts categorical values into numbers, and skips invalid records. The average_ranks function assigns ranks to values and calculates average ranks for tied values. The correlation_or_none function calculates Pearson correlation when sufficient valid data is available. Finally, the main program calculates the three correlations between social media habits and perceived stress, displays the results, and identifies the habit with the strongest observed association by comparing the absolute correlation coefficients.
